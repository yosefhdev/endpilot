# Contribuir

1. Crea una rama desde `main`.
2. Antes de abrir el PR, pasa los checks de la sección "Checks" del [README](README.md). CI corre los mismos.
3. Un PR por cambio. Si toca el protocolo de sincronización, incluye pruebas de concurrencia y de red inestable (ver PLAN.md §6).
4. Las decisiones de arquitectura se registran como ADR en `docs/adr/`.
